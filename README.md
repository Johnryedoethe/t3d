# T3D

This app has been set up with Tauri + Vanilla TS.

To install dependencies:

```sh
npm install
```

To install dependencies for Android and iOS app:

```sh
npm run tauri android init
npm run tauri ios init
```

To start desktop app in development mode:

```sh
npm run tauri dev
```

To start desktop app in development mode:

```sh
npm run tauri android dev
npm run tauri ios dev
```

## controls for app

For transformations

{g, s, r} for the base transformations

{x, y, z} for choosing an axis

{q} to quit transformation to select new objects
